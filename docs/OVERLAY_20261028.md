# Overlay nativo — 28/10/2026

O overlay do Server16 passa a desenhar com um estado D3D11 próprio. O estado
anterior do FIFA é restaurado pelo contexto, sem repetir os vínculos individuais
de vértices interceptados pelos modelos animados do mod.

Antes da restauração, o estado do overlay é limpo para não reter RTVs/SRVs do
backbuffer entre redimensionamentos da janela. A saída por exceção também chama
a restauração. Quando a API de contexto independente não está disponível, o
caminho de desenho já existente continua em uso.

Arquivos desta revisão:

- `server16_py/d3d_overlay/cgfs16_overlay.cpp` e `ui_pipeline_state.h`;
- `bin/cgfs16_overlay.dll`, igual ao overlay instalado no FIFA Friends V12.

O Server16 permanece na versão 0.2.19. Não houve alteração de Python embutido,
bootstrap, áudio, texturas de estádio ou executável congelado nesta revisão.
O host do mod carrega a DLL instalada; atualize também a branch
`fifa-friends-v12` do FIFA Friends para manter os dois projetos compatíveis.

A revisão conjunta inclui competições, copas, time do campeonato, perfil do
técnico, acesso ao elenco pelo vestiário e recuperação do serviço de empréstimos.
Esses recursos e seus testes pertencem ao repositório do V12. O teste nativo de
isolamento gráfico exercita trezentos quadros com cards variáveis, conserva os
materiais do jogador e verifica a liberação do backbuffer antes de redimensionar.
