# Server16 / FIFA Friends — 02/11/2026

Versão 0.2.19, branch `fifa-friends`. Fontes sincronizados com o jogo e com o
FIFA Friends V12, incluindo opções da carreira, áudio/anúncios de substituição,
limpeza de recursos temporários e correções de troca de estádio.

O autoteste congelado cobre os novos módulos e as dependências existentes.
A suíte do Server passou em 651 testes. O executável publicado com o V12 foi
reconstruído com os módulos atuais, preservando os demais recursos e offsets
do importador das sessões em execução. Reinicie o Server para ativar o código
novo da aplicação principal.

Os testes da tela de narração de desenvolvimento agora abrem a ação nominal,
sem pressupor que o quarto card público ainda é o seletor oculto de narradores.
A ponte Lua usada pelas regressões de estádio é uma dependência de testes.
O seletor experimental continua oculto no produto público.

Use junto da branch `fifa-friends-v12` e do delta
`FIFA-Friends-Assets-Delta-20261102-sobre-20261030.zip`, aplicado sobre os assets
de 30/10/2026. O delta inclui técnicos, imagens, vestiário e recursos externos
novos/alterados. Código e executáveis vêm do Git; nenhum save ou runtime acompanha
a entrega. Veja as notas completas em `ModCarrerMode/docs/RELEASE_20261102.md`
no repositório do FIFA Friends.
