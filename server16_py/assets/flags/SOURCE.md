Country flag assets downloaded from https://flagcdn.com/w40/ using the official
Flagpedia API: https://flagpedia.net/download/api (retrieved 2026-10-03).
Based on Wikimedia Commons flag artwork, supplied by Flagpedia/FlagCDN.
Included locally so the stadium selector never needs network requests.
Country mappings use the FIFA codes already parsed from installed package names;
unknown codes retain their text and do not receive an invented flag.
